# VIDEO FRAME  
 KDE Plasma widget for playing videos/gifs/animations/clips in a frame on the desktop or panel, mainly for decorative purposes.  

**KDE STORE:**  
https://store.kde.org/p/2363278  

> [!NOTE]
> **🔷 - FEATURES**
> Features:
> - Single video.
> - Folder support.
> - Random order for folders.
> - Panel support(with custom width).
> - GIF support(including transparent gifs).
> - Playback speed control.
> - Volume and muting.
> - Frameless and opacity settings.
> - Fill modes.
> - Desktop seekbar support.
